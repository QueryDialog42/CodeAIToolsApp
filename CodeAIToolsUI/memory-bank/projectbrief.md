# Project Brief

## Project Name
CodeAIToolsUI

## Project Type
Desktop Application (Avalonia UI)

## Core Purpose
A collaborative code development platform that integrates AI-powered code assistance with team collaboration features. The application provides two user roles (Admin and Worker) with different capabilities for managing projects, writing code, and leveraging AI for code explanation and transformation.

## Primary Goals
1. **Code Development Environment**: Provide a dual-pane editor for flow diagrams and code implementation
2. **AI Integration**: Enable AI-powered code explanation and transformation features
3. **Team Collaboration**: Support project sharing and team management with role-based access
4. **GitHub Integration**: Facilitate repository creation and management through GitHub API
5. **Local Project Management**: Maintain local project structure with flow and code files

## Target Users
- **Admins**: Project creators who manage teams, assign duties, and oversee project structure
- **Workers**: Team members who work on assigned tasks, write code, and utilize AI assistance

## Key Features
- User authentication (login/register) with role-based access
- Project creation with collaborator selection
- File tree navigation for local projects
- Dual editor system (Flow.txt and Code.txt)
- AI code explanation and transformation
- GitHub repository integration
- Team and duty management
- Terminal output for code execution (Java)

## Project Scope
The application serves as a desktop client for a broader system that includes a backend API (localhost:8080). The UI handles user interactions, local file management, and communicates with the backend for user management, project data, and AI services.
