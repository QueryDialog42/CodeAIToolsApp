# CodeAI Tools Project Brief

## Project Overview
CodeAI Tools is a comprehensive software development platform that combines AI-powered code assistance with collaborative project management capabilities. The system consists of a Spring Boot backend database service and an Avalonia-based desktop application frontend.

## Core Requirements

### Primary Features
- **User Management**: Role-based authentication (Admin/Worker) with registration and login
- **Project Management**: Create, manage, and organize development projects
- **AI Code Assistance**: Code explanation and transformation services
- **GitHub Integration**: Repository management, token handling, and collaboration
- **Team Collaboration**: Admin and worker role management with project assignments
- **Subscription System**: User subscription management for premium features

### Technical Architecture
- **Backend**: Spring Boot 3.4.2 with Java 21, JPA/Hibernate, MariaDB
- **Frontend**: Avalonia UI (.NET 10.0) desktop application
- **API Communication**: RESTful APIs with JSON serialization
- **Database**: Relational database with entity relationships

### User Roles
- **Admin**: Full system access, user management, project oversight
- **Worker**: Project participation, code assistance tools, collaboration features

## Project Goals
1. Provide an integrated development environment with AI assistance
2. Enable seamless team collaboration on coding projects
3. Automate routine development tasks through AI integration
4. Maintain secure and efficient project management workflows
5. Support scalable subscription-based premium features

## Success Metrics
- User adoption and engagement rates
- AI assistance accuracy and usefulness
- Team collaboration efficiency improvements
- System reliability and performance
- Subscription conversion rates
